## 4. 学到的（保留给 M5+）

1. **文档漂移是常态**：入口文档三个里程碑一过就落后——对齐是周期成本不是一次性投入（#78 与本 PR 的 DOC-INDEX 翻转同构）。
2. **摩擦台账是资产**：F1→F69 六十九项，每一项都有登记-裁决-闭环指针——灰度/推广的信心来源不是"没问题"而是"问题都有去向"。
3. **环境性腐烂无声**：短命证书（F61）、cron PATH（F62）、工作区挂载（F69）、工具链钉版被漏洞库追上（sbom 四层洋葱）——**运行时配置的生命周期必须与正式纪律一致**。
4. **并行度由冲突图决定**：F58 队首串行化的发现与修复（W8）证明：并行的上限不是意愿而是变更面的物理重叠度。
5. **人审通道与门禁分层**：F44（Mimosa ask 裁决）确认了"工具报告、人裁决、门禁照过"的分层——安全工具是护栏不是法官。
